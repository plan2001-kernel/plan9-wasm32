Installing

  1. Power on: the machine boots the CD image from this site, or the system on the browser's disk. The ISO is also there to download, once, if you want a local copy.
  2. The virtual Ethernet is connected by default: the machine gets its address, DNS and gateway from this server, and its traffic is routed to the Internet. There is no passkey and no network prompt.
  3. In rio: inst/start. Choose sdW0, GPT and hjfs; choose / as the distribution disk and as the archive location. The installer copies the prebuilt system to this browser's disk and reboots into it.
  4. To update it: the source, then the tools that build it, then the rest:
    bind -ac /dist/9front /; cd / && git/pull
    cd /sys/src/cmd; for(i in cc 3c 3a 3l cpp mk) @{cd $i && mk install}
    mk pcc.install yacc.install; cd /sys/src; mk install

The ISO contains the prebuilt tools, libraries and applications. Ghostscript is excluded. A fresh browser disk needs 1792 MiB of storage. Reinstall from BIOS → Boot once from CD. Reaming the filesystem erases the existing Plan 9 disk.
